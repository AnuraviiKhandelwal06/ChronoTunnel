# ChronoTunnel — Project Documentation

This directory contains the technical and analytical documentation for ChronoTunnel, an urban mobility intelligence platform focused on understanding New York City's subway ridership patterns.

The documentation describes the system architecture, data infrastructure, analytical methodology, implementation details, and project limitations.

## Project Scope

ChronoTunnel transforms public transit ridership data into mobility intelligence through:

- Temporal ridership analysis.
- Station-level demand analysis.
- Borough-level comparisons.
- Geospatial demand visualization.
- Statistical investigation.
- Evidence-based planning recommendations.

## Data Source

The project uses the MTA Subway Hourly Ridership dataset covering 2020–2024, published through NYC Open Data.

**Dataset ID:** `wujg-7c2s`

## Technology Overview

The platform uses Python and its data-science ecosystem, DuckDB for analytical data access, and Streamlit for the interactive application.

Refer to the individual documentation files for implementation details, architectural decisions, analytical methods, and execution instructions.
